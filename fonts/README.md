# Fuentes

- **Quicksand** — Andrew Paglinawan. SIL Open Font License 1.1.
- **DM Mono** — Colophon Foundry / Google. SIL Open Font License 1.1.

Alojadas aquí a propósito, en vez de cargarlas desde Google Fonts: así el navegador de
quien visita kiplook.com no hace ninguna petición a servidores de terceros. Encaja con lo
que promete la política de privacidad.

Solo se incluye el subconjunto `latin`, que cubre los acentos y la ñ del español.
